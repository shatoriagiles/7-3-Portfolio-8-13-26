# 7-3-Portfolio-8-13-26
The app I developed is an inventory tracking app that helps users manage items and their quantities. The main goal was to make it easy for someone to see what they have, add new items, update amounts, and remove items they no longer need. The app also allows users to create an account and log in so their information can be saved. Another useful feature is the ability to send a text alert when an item reaches a low amount. This was designed to help users avoid running out of important supplies.

The main screens included a login screen, account creation screen, and an inventory screen that displays items in a grid. Users can add new items, edit the quantity of an item, and delete items. I tried to keep the design simple so users would not have to search for important features. Buttons and information were placed where they were easy to find. I also made sure the app could still work even if the user did not allow SMS permission. The text alert feature is optional, while the main inventory features still work normally. I think this makes the app more user-friendly because users have more control.

When coding the app, I worked on one feature at a time instead of trying to build everything at once. I first focused on the basic screens and then connected the features to the database. I used SQLite to store inventory information so it would still be there after the app was closed. I also tested features as I added them. This approach helped me find problems before moving on to another part of the app. In the future, I can use the same strategy on larger projects by breaking them into smaller tasks.

Testing was very important during development. I tested the login, account creation, adding items, editing quantities, deleting items, and saving data. I also closed and reopened the app to make sure inventory information was not lost. Testing showed me that a feature may work once but still have problems in other situations. One challenge was making different parts of the app work together without breaking other features. I had to make changes and test again until everything worked correctly.

I think I was most successful with the inventory management features and database storage. I was able to connect the user interface to SQLite and support creating, reading, updating, and deleting inventory items. This part of the project showed my understanding of both app design and programming. It also showed me how important planning, testing, and problem solving are when creating a complete mobile application.
